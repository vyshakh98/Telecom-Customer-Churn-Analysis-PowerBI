# Telecom Customer Churn Analysis | Power BI

## Project Overview

This project focuses on analyzing customer churn in the telecommunications industry using Microsoft Power BI.

The objective is to understand customer behavior, identify potential churn patterns, analyze customer risk factors, and provide insights that can help businesses improve customer retention.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Cleaning and Transformation
- Data Visualization

## Dataset

The project uses a telecommunications customer churn dataset.

The cleaned dataset contains 7,032 customer records and 25 columns.

Key attributes include:
- Customer demographics
- Tenure
- Internet and phone services
- Contract type
- Payment method
- Monthly charges
- Total charges
- Churn information
- Customer Lifetime Value (CLTV)
- Churn Score

## Dashboard Pages

### 1. Executive Overview

Provides a high-level overview of customer churn and business performance through interactive visualizations.

### 2. Customer Risk Analysis

Focuses on customer churn risk and helps identify customer segments that may require retention strategies.

## Key Objectives

- Analyze customer churn patterns.
- Understand the relationship between customer characteristics and churn.
- Examine the impact of contract types and payment methods.
- Identify customer segments with potential churn risks.
- Present insights through interactive Power BI dashboards.
